# นิราศวัดเจ้าฟ้า — Interactive Scrollytelling (ฉบับอัปเดตใหม่ทั้งหมด)

## วิธีเปิดใช้งาน
1. แตกไฟล์ ZIP นี้ลงในโฟลเดอร์เครื่องของคุณ
2. เปิดโฟลเดอร์ `nirat-scrollytelling` ด้วยโปรแกรม **VS Code**
3. คลิกขวาที่ไฟล์ `index.html` แล้วเลือก **Open with Live Server**
4. หากเคยเปิดหน้านี้ไว้ก่อนหน้านี้ ให้กด `Ctrl + Shift + R` เพื่อล้างแคชภาพเก่า
